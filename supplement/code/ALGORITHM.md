# 当前唯一提案：释放冲突路径搜索RCR

入口rosr/policy.py，内部版本release_conflict_continuation_2026-10-25；指纹与默认参数见frozen_latest_policy.json。Density、Joint DR、Coalition-V及经典迁移方法是比较控制。当前运行依赖统一位于runtime/；工作目录不保留旧算法目录或实验数据。

## 可执行延续与价值保持

continuation.py保存上一轮接受的完整可行见证。每个事件移除已完成/正在处理报告及路线中不再pending的任务，用当前真实状态重新计算路线、FIFO释放和原处理顺序；过期承诺、任务参数变化或物理合同变化显式使见证失效，记录原因并回退初始化。可行见证与普通快照求值缓存不同，不能不经验证跨事件使用。

令G为已完成价值、按时完成的锁定处理价值和剩余计划价值之和，三个集合去重。若每一步真实执行精确、延续见证有效、接受的新剩余计划价值不低于旧延续，则执行只在三个集合之间转移价值，替换不减少剩余价值，故G逐事件不减；有限终止时G全部兑现。新到达任务可拒绝、既有传输不受其强制干扰时，旧延续仍可作为备选。代码逐事件检查该不变量；失效时不再宣称跨该事件的保证。这不是优于独立运行Density/旧RCR的定理。

Density作为延续基线的候选，适用统一接受门控。有效旧延续在无法改善时被保留，所以当前方案不保证高于每个事件重新计算的Density价值。同首动作但更高价值的可行尾部允许更新。解码后的可接受候选按首动作归组，各组保留按价值、已采集留存和实际紧凑性排序最好的见证。相同路线首任务的列不合并，避免丢失不同释放和冲突的尾部。

## 等价密度初始化

完整构造按增量价值/车辆与处理资源择优，每次可插入新任务或替换一个已选报告。插入j、删除h的增益v_j−v_h以及旅行增量可在处理可行性判定前确定。精确排序并返回首个可行候选，与评价全部候选后选最优等价。整数价值总绝对量≤2^52时启用；其他输入保留穷举评价，不改变浮点破平。

路径/方案缓存只在当前公开快照内有效。按删除报告价值形成候选流，堆惰性合并；旅行标量仍按原逐段顺序累加。密度上界延后展开低优先级插入；忽略释放时刻的必要截止期容量检查排除不可能的添加/删除组合。通过容量检查仍须完整下游检验。初始化等价性与网络边界由保留的机制测试检查。

必选报告的EDF、预留EDF和密度见证使用等价O(n log n)实现：按释放排序，以相同完整优先级维护堆；任一必选报告超期即可返回失败。全部已到达时直接排序；相同序列不重复构造方案。可选报告仍使用原选择算子。兼容车辆、车辆起点和直达旅行在当前快照缓存，旅行累加及候选破平顺序保持不变。

## 不可抢占强制区间占用

令r为不早于锁定处理结束的有效释放，d为截止期，p为处理时长。对任意a<b，连续执行的报告在[a,b]内的最小占用为

    e_j(a,b) = max(0, min(p_j, b-a, r_j+p_j-a, b-d_j+p_j)).

证明：任务起点在[r_j,d_j-p_j]内，区间交叠长度在最左/最右安排之一取得最小值。单处理器容量因而要求sum_j e_j(a,b)x_j <= b-a。主模型用每条路径的真实FIFO释放形成系数；初始化只对必选集合使用必要检查，不把可选报告强制纳入。代码将截止期放宽EPS并使用保守求和余量，包含数值上有效的见证。选择有限关键区间只影响检出能力，不影响每条割的有效性；通过检查仍须实际不可抢占调度。

例如(r,d,p)=(0,4,2)、(1,3,2)通过原完整时间窗容量检查，但在[1,3]内强制占用分别为1和2，合计3>2。新割直接排除该不可抢占冲突。其理论基础是已有energetic reasoning；本实现将其作用于路径相关释放，不将通用不等式声明为新定理。

## 路径与留存目标

保留空路径、所有可行单任务路径与完整初始化锚点。一般深度3、目标64路径；多停靠替代兼顾价值密度与报告松弛，受保护路径可超过目标。所有新采集必须出现在可行的报告处理序列里。

有效历史冲突中的任务优先扩展，并补充至多8条提前释放的多任务替代；不会挤掉原密度/松弛保留项。路径扩展检查剩余预算，空路径、单任务和完整锚点仍受保护。此处为冲突引导的有限池搜索，未实现完整列生成或全局定价证书。

第一目标最大化原始可见价值，并保护初始化价值。证明可行主目标最优后固定该价值；对已承诺报告的整数留存价值，令其最大公约数为g，空集合取g=1。路线资源项C非负，一车最多选择一路，因此U=各车最大单路资源项之和是整个C的上界。次级目标为−留存价值/g+C/(2U+1)：资源变化小于1/2，不能抵消一个整数留存单位。没有固定大权重100，也不无条件声称任意实数价值有单位间隔；分数留存值使用独立留存阶段再优化资源。默认整数工作负载只有两个目标阶段，每阶段仍可能因有效性割而多次求解。

## 先见证，再认证冲突

EDF、预留EDF和密度规则先构造可行见证，再用保持截止期的相邻交换改善总完工。见证失败且作业≤14时，子集DP精确判定固定集合。较大集合只在首个EDF超期附近选≤14个作业精确检验；子集精确不可行才认证全集不可行。可行局部子集并不证明全集可行；unknown不产生割。

从认证集合删除作业，预算允许时得到删除极小冲突；预算中止时保留已认证、可能非极小的集合。对至多8报告的冲突，最多6次精确试验降低释放下界，只接受仍被精确判定不可行的试验。较低释放下界覆盖旧割的全部排除区域，故强化割支配原割。

至多64条证书跨事件保存，记录任务处理时长、绝对截止期、释放下界及证明时的处理器可用时刻。只有完整任务集合仍存在、参数一致、处理器可用时刻不早于证明时，才重新实例化或匹配该割。更早释放、任务缺失、截止期/工作量变化不满足复用条件。强制区间超载本身也可产生不可行证书。此处应用既有逻辑分解原则，路径池最大规模不是全局邻域穷尽证明。

## 有证据的提前返回

先排除单任务都不能完成的报告。对每个截止期d，截止期不晚于d的任务共享至多d−A_e的处理时间；忽略路径和报告释放，分数背包给出该前缀的价值上界。加上更晚截止任务的全部价值，再对各前缀取最小值得到安全上界；整数值用保守浮点余量向下取整。达到上界只停止严格价值搜索；若独立Density方案价值不低于基线且首动作不同，则仍触发受预算限制的资源搜索。此触发器不保证穷尽全部等价值动作。

便宜上界在初始化前计算，每次成功插入后检测L>=U。初始化仅接受严格正价值增益，因此达到安全上界证明后续遍历无法成功，完整初始化的最终key/score不变。该计算耗时计入附加搜索预算。

对至多48个可能报告，在便宜上界未达到时，以各兼容车辆单任务真实释放的最小值为释放下界，建立前缀和强制区间占用的分数选择LP。曼哈顿旅行三角不等式、非负采集和FIFO单调性保证该下界不会晚于任意对应路径释放。对于Ax<=b、0<=x<=1、最大化v*x，任何lambda>=0给出

    U(lambda) = b*lambda + sum_j max(0, v_j-(A^T lambda)_j).

代码从LP的对偶边际值重建非负lambda并重新计算该弱对偶证书；不使用超时原始解作为上界。无有限边际值时返回便宜上界；有限边际值即使未最优也只影响界的紧度。全选已满足全部LP约束时省去求解。保守浮点余量与整数舍入后取两级上界较小值。

## 接受与计算

严格增益和等价值候选统一要求价值不降低，并覆盖立即占用代价E。对车辆、上传阶段，以基线新启动队首的价值/该阶段释放延迟作为可见密度，对候选增加的延迟计价并在各车辆上求和；处理器同样以基线立即启动报告的价值/处理时长计价。E取三个阶段费用的最大值，避免同一报告跨阶段重复累加。无基线新启动任务的资源价格为零。接受须满足候选价值−基线价值≥E−EPS。

E具有价值量纲，但只是未调权的启发式，不是未知到达损失的上界；位置变化仅记录，未建立空间预测价值。严格增益不绝对保护已采集任务或原松弛度，防止沉没成本成为否决有益交换的理由。等价值候选还要求已采集报告留存不减少，总旅行、未锁定车辆占用和相对边缘完工和均不增加、至少一项下降超过1e−4分钟，空闲车队首占用不增加；松弛度下限为min(1,max(0,基线最小余量))，空基线取0。

主目标被证明与基线持平时，次级模型加入旅行、车辆占用、已采集报告留存、队首限制及处理完工和必要下界；判定器使用d−m，m为上述动态松弛度下限。该分支冲突不进入原截止期缓存。被动作门控拒绝的严格增益候选可加入至多4条精确赋值排除，继续寻找可接受替代；这些排除不是物理不可行证明，不跨事件复用。排除后最优性仅标记为restricted_master_optimal，也不保证遍历同赋值的其他可接受处理顺序。

附加墙钟目标0.1秒包含前置上界、LP上界、路径生成、建模、求解、认证及解码；最多16次主模型求解、8条调度冲突割、4条动作拒绝赋值排除，历史证书另计。HiGHS显式threads=1，初始化、延续重建及最后验证/记录另计；不可中断调用和受保护路径构造可能越过目标。计算不推进物理仿真时间。单线程不消除墙钟停止受调度影响的可能。
