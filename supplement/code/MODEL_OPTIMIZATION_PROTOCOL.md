# 当前算法实验约定

仅维护当前 RCR 实现。必要比较控制由同一物理执行器运行，Density 和 Joint DR 共享初始化及处理判定器；Coalition-V 是作者构造的价值一致强化控制。所有方法仅使用已公开状态。

默认 RCR 额外搜索目标0.1秒，深度3，beta=0.25，整数留存使用有界合并次目标，固定TDMA/FIFO上传采用slot=0.025与rate=1。求解器单线程；墙钟停止可能产生执行变化。

`run_rosr_bench.py` 运行参考工况；`run_model_bench.py` 运行完整b/c/u组合；`run_scale.py` 运行指定车队规模。实例内方法共享任务流，运行记录含当前源码指纹并执行物理资源和动作检查。固定上传场景包含七种方法，共享上传场景使用三种兼容解码方法。

统计单位为独立任务流；相关因素格不能当作额外独立重复。需要比较时同时报告价值、任务数量、规划耗时及不利结果，配对区间注明是否经过多重比较校正。改变决策规则后应使用新的确认种子。

当前实现为release_conflict_continuation_2026-10-25，77项机制测试。可行延续在当前状态重建，Density和RCR候选对同一延续基线使用增益/可见占用代价门控；原Joint DR的接受规则通过guarded=False保持不变，但恢复对同首动作尾部增益的接受（公平性修复N1）。保证价值对已完成、锁定处理和剩余计划去重计数，延续有效时逐事件检查不下降。动作归组仅作用于已解码候选，不合并不同尾部的路线列。

先计算便宜安全上界，初始化达到上界时安全停止；达到上界后，若Density提供不同且不低价值的首动作，仍可执行资源搜索。前置上界耗时扣除附加预算；初始化、延续重建和最终验证/记录另计。附加搜索包含至多5毫秒的48报告释放LP、路径池、能量割、至多64条历史不可行证书及小冲突强化。持平分支使用d−m，m=min(1,max(0,基线余量))，空基线取0；分支证书与原截止期缓存隔离。至多4条行为赋值排除不作为不可行证明存储。位置释放状态可记录，但不声称已有空间预测或随机Q值保证。

## 2026-10-25 性能修订（release_conflict_continuation_2026-10-25）

在不降低保证的前提下实施T0工程优化与对照公平性修复。决策规则有两处显式变化，旧确认数值不可复用：

1. **价值上界门控**：延续有效且便宜上界不超过延续方案价值时跳过全量density重建。紧凑持平模式改为有界局部探测（`local_equal_value_probe`），发现不同首动作的等值方案才触发资源搜索；严格价值模式直接保留延续。价值不降与延续不变量保持不变。
2. **对照公平性**：Joint DR恢复接受同首动作尾部增益（N1）；Coalition-V评价与其它方法一致要求采集必须有可行处理（N2）。

实现层另含前缀和容量判定、快照浅拷贝、位DP缓存共享、解码双重预测消除等语义等价优化。77项机制测试与`verify_package.py`全绿。任何比较数值需用新种子重新确认。

本代码分发不包含原有实验数据、聚合结果、审计报告或分析脚本；执行实验会生成新数据。论文2306次确认来自2026-10-21冻结配置，不作为当前决策修改的确认。当前16条开发诊断复用8车主工况、处理器拥挤、紧截止期各4流，FIFO全因素2流，以及16/32车各1流；参考种子20401000/1与20411000/1，FIFO种子20401002/3，规模种子20401004。与上一轮已记录结果逐流校验输入指纹；计时不是随机交错复测。曾尝试把已采集价值和松弛度作为严格增益硬门槛，因开发退化撤销，故这些流明确属于开发证据；未调节价格权重。最终3653次决策无延续失效/保证下降，77项测试通过；FIFO和32车不利结果完整披露。后续确认必须另行冻结并使用未打开种子。
